# Chili Disease Detection

## Installation

### Clone Project

```
    git clone https://github.com/IlmanNafi11/chili-disease-detection.git
```

### Install Package

```
    pip install -r requirements.txt
```

### Cara Menjalankan API

```
    uvicorn main:app --reload
```

### Cara realod API

```
    uvicorn main:app --reload
```
